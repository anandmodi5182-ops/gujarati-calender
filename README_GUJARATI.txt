ગુજરાતી પંચાંગ Live Wallpaper — Android Studio Project

આ ZIP Android Studio project છે; APK નથી. આ પર્યાવરણમાં Android SDK વડે APK build/verify કરી શકાતું નથી.

APK બનાવવા:
1. કમ્પ્યુટરમાં Android Studio ઇન્સ્ટોલ કરો.
2. આ ZIP extract કરો.
3. Android Studio > Open > GujaratiPanchangLiveWallpaper ફોલ્ડર પસંદ કરો.
4. Gradle sync પૂર્ણ થવા દો.
5. Build > Build Bundle(s) / APK(s) > Build APK(s) પસંદ કરો.
6. app/build/outputs/apk/debug/app-debug.apk ફોનમાં મોકલી install કરો.
   ફોનમાં “Install unknown apps” માટે મંજૂરી આપવી પડી શકે.

ફોનમાં વાપરવું:
1. એપ ખોલો.
2. “Live Wallpaper સેટ કરો” દબાવો.
3. Preview માં “Set wallpaper” દબાવો.
4. તમારા Android ફોનમાં Lock screen નો વિકલ્પ દેખાય તો “Home screen and lock screen” પસંદ કરો.
   કેટલાક Android ઉત્પાદકો lock screen પર live wallpaper મંજૂર કરતા નથી; તે ફોનના OS પર આધારિત છે.

નોંધ:
- મૂળ HTML ના પંચાંગ ગણતરી/ડેટા જાળવ્યા છે; પંચાંગની ગણતરીની સ્વતંત્ર ચકાસણી કરેલી નથી.
- આ પ્રોજેક્ટ ઇન્ટરનેટ વિના HTML માં રહેલા ગણતરી આધારિત ભાગ ચલાવે છે; Google Fonts માટે ઇન્ટરનેટ ઉપલબ્ધ હોય તો જ ફોન્ટ લોડ થઈ શકે.
- જો ફોન પર wallpaper ખાલી દેખાય અથવા અટકે, તો અલગ Android ઉપકરણ પર ટેસ્ટ/ડિબગ જરૂરી રહેશે.
